Retail Shop

A demo storefront running on Kubernetes through GitOps.

Application services

  • Catalog: catalog:8000/products (MariaDB)
  • Cart: cart:8000/cart (DynamoDB Local)
  • Checkout: checkout:8000/checkout (Redis)
  • Orders: orders:8000/orders (PostgreSQL and RabbitMQ)

Backend services

PostgreSQL, Redis, DynamoDB Local, MariaDB, and RabbitMQ run as in-cluster services for this workshop demo.
